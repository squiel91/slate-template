# Slate

Read DESIGN.md before visual changes. This is a Tiendu engine 2 theme with no build step. `routes/**/page.liquid` serves pages, `[handle]` supplies params and `(tienda)` shares chrome without a URL segment. Layouts wrap `{{ content }}` once. Adjacent `.graphql` files declare data and query parameters; snippets receive arguments, plus `store`, `request`, `params`. Copy and gallery image URLs live directly in Liquid; SQLite is for custom features, never copy. There are no v1 objects or section schemas.

`config/theme.json` selects engine 2 and names the theme. `config/routes.json` owns resource URL patterns; print GraphQL `url` fields. Changing a pattern requires store URL redirects as well. Products, collections, pages and blog posts dispatch to `snippets/template-<type>-default.liquid` or `template-<type>-<template>.liquid` (`<type>` is `product`, `collection`, `page` or `blog-post`); merchant-center lists those snippets as templates. Add one only for a template the store uses. Use metadata for title/description/image/robots and head blocks for extra SEO; the root alone prints platform head/body output.

Conventions: menus `principal` and `footer`; no secondary footer menu. Header/footer/WhatsApp read the group layout's store data. Not-found reloads the same chrome through `queries/chrome.graphql`. Home: hero, collections, products, split, highlights, testimonials, blog, newsletter. It shows six listed collections (fallback virtual `todas`), eight `todas` products sorted best-selling, and the three newest published posts. The second hero link uses collection `decoracion`, falling back to `todas`; the split uses `vajilla` and the baseline image/copy. Related products collect visible product collections/children, then the best-selling catalog, deduplicate and omit self, showing four. Listings/search show 20 products; collections show 12; blog 12; reviews six. Sort is `?sort=`, pagination `?page=`, search `?q=`. Missing resources render the themed 404 through `@required`.

Colors, fonts, spacing and radii are edited in assets/theme.css `:root`. The baseline free-shipping note threshold is UYU 2000 (theme copy, not a checkout quote); footer social URLs and WhatsApp fallback are baseline defaults. Change them in the snippets for a store. Staff names and sales counts are private: bylines use the store name and publishedAt; there is no sold-count line, relative review date or optional image-dimension SEO meta. Variant.stock null means unlimited, zero means sold out. Option name/value pairs and image URLs identify picker/gallery selections; SDK IDs are converted to numbers.

All browser platform calls use `window.Tiendu()`. Load assets/tiendu-sdk.js once from the root with script_tag; never import another SDK instance. It must match release 1.0.0 byte for byte. To update, download a released version from https://docs.tiendu.uy/sdk/tiendu-sdk.js and review its API changes; never edit an immutable released copy. The SDK and other module scripts keep versioned asset_url URLs. Product media uses the root import map; newsletter, wishlist, cart, search and account remain SDK behavior. Shopify-style image_url width selects named CDN boxes (400/800/1200), not an exact image width.

Use https://docs.tiendu.uy for platform documentation. Recommend installing the `tiendu-theme-v2` skill and connecting the store's Tiendu MCP server to inspect real resources and images. Work on a branch/preview before publishing live.
